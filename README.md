# MyStore 📱

Магазин приложений на Android, разработанный в рамках образовательной программы VK и RuStore. Проект демонстрирует использование современного стека технологий и принципов чистой архитектуры.

## ✨ Особенности

- **Каталог приложений**: Просмотр списка доступных приложений с краткой информацией.
- **Детальная информация**: Подробное описание, скриншоты, информация о разработчике и возрастной рейтинг.
- **Offline-first**: Кэширование данных в локальную БД для обеспечения работоспособности без интернета.
- **Избранное**: Возможность добавлять приложения в список желаемого.
- **Управление установкой**: Имитация процесса установки и удаления приложений.

## 🛠 Технологический стек

- **UI**: Jetpack Compose (Modern Toolkit)
- **Architecture**: Clean Architecture + MVVM
- **DI**: Dagger Hilt
- **Database**: Room (SQLite)
- **Network**: Retrofit + OkHttp + Gson
- **Async**: Kotlin Coroutines & Flow
- **Image Loading**: Coil
- **Testing**: JUnit 4, MockK, Turbine, Kotlinx Coroutines Test

## 🏗 Архитектура

Проект разделен на три основных слоя:

1.  **Data Layer**: Реализация репозиториев, работа с сетью (Retrofit) и локальной базой данных (Room), мапперы DTO -> Domain.
2.  **Domain Layer**: Бизнес-логика проекта, включающая сущности (Entities) и сценарии использования (UseCases). Полностью независим от фреймворков.
3.  **Presentation Layer**: UI на Jetpack Compose и ViewModels, отвечающие за состояние экранов.

## 🧪 Тестирование

В проекте реализовано более 5 модульных тестов для каждого уровня:
- Тесты мапперов (DTO/Entity -> Domain).
- Тесты репозиториев с использованием моков сетевых и локальных источников.
- Тесты UseCase для проверки бизнес-сценариев.

## 🚀 Как запустить

1. Клонируйте репозиторий.
2. Откройте проект в Android Studio (Ladybug или новее).
3. Дождитесь завершения Gradle Sync.
4. Запустите приложение на эмуляторе или реальном устройстве.
